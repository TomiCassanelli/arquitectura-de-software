# Microservicio de clientes

Crear aquí el servicio responsable de clientes.

Debe:

- Escuchar en `:8081`.
- Implementar `POST /clientes`.
- Implementar `GET /clientes/:id`.
- Separar controlador, servicio y repositorio.
- Usar datos en memoria.

No copiar la lógica de productos, pedidos ni RabbitMQ. Esas responsabilidades pertenecen al otro microservicio.
