# Actividades — Clase 7: balanceadores de carga

Estas actividades parten de un servicio de clima real, pero la infraestructura
está mal configurada. El trabajo es diagnosticar el síntoma, corregir la arquitectura 
y comprobar el resultado.

## Requisitos

- Docker Desktop iniciado.
- Docker Compose v2 (`docker compose version`).
- Conexión a Internet: las APIs consultan Open-Meteo.

Cada estudiante recibe en el formulario un bloque propio para `config/config.go`
con ciudad, coordenadas y mensaje. Debe copiarlo completo antes de comenzar y
usar el mismo formulario para registrar la respuesta inicial, el diagnóstico y
la evidencia final.
