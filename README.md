# Arquitectura de Software

Repositorio de la materia Arquitectura de Software de la carrera de Ingeniería en Informática de la UCC.

Este espacio se utiliza para organizar el material de clase y los trabajos prácticos asociados. La idea es trabajar con una rama por clase, donde cada branch contiene el contenido visto en el aula junto con el TP correspondiente.

## Organización del repositorio

- `main`: rama base del repositorio.
- `branches de clase`: cada clase tendrá su propia rama con el desarrollo y las consignas del TP asociado.

## Objetivo

El repositorio está pensado para acompañar el cursado de la materia, dejando disponible en cada branch el estado de trabajo de una clase determinada. De esta manera, los estudiantes pueden revisar el contenido, retomar avances y ubicar con claridad qué TP corresponde a cada instancia.

## Uso

1. Elegir la branch de la clase que se quiere revisar.
2. Abrir el material y el TP cargados en esa rama.
3. Continuar el trabajo sobre la base indicada para esa clase.
