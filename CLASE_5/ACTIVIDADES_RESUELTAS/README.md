# Actividades resueltas

Estas son soluciones de referencia para corregir o explicar después del trabajo práctico. Las consignas y los `TODO` originales permanecen en [`../ACTIVIDADES`](../ACTIVIDADES/README.md).

```text
ACTIVIDADES_RESUELTAS/
├── actividad-1/  consultas de Solr completadas y comentadas
└── actividad-2/  API Go + Gin terminada, con separación por capas
```

Ambas actividades usan el mismo Solr iniciado desde `CLASE_5`. Ejecutar primero el [setup común](../README.md).

> La solución de la actividad 2 incluye `total`, tomado de `numFound`. Es una mejora intencional frente al esqueleto: así se distingue el total de coincidencias de los documentos limitados por `rows`.
